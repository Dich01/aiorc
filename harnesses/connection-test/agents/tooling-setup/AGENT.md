# tooling-setup

Make sure the repository has ESLint and Prettier, so the lint-format step can
run them. Follow the tooling install skill exactly.

You are the only agent of this flow allowed to change the repository, and
only to install those two tools and their minimal configuration. If they are
already installed, change nothing. If the installation fails or a command is
not allowed, report it: lint-format will then report that the tools did not
run.
