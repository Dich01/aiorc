# Spanish (Latin America) glossary

Target: neutral Latin American Spanish (es-419). Address the user as "tú" (never "vos", never "vosotros").
Use Latin American vocabulary: computadora, archivo, correo electrónico, celular, guardar, borrar/eliminar.
Tone: plain and sober, like the English. No emojis.

## Keep in English (technical terms)

MCP, API, API key, token, JSON, YAML, URL, endpoint, webhook, SDK, CLI, CI, SQLite, hash, ID,
skill / skills, fork / forks (verb: "hacer un fork"), commit, branch, merge, pull request / PR, diff,
prompt, harness, benchmark / benchmarks, Markdown, Claude, Claude Code, GitHub, AIOrc,
lint, build, timeout, runtime, schema, stdout/stderr, log / logs (noun), dashboard only when it names an external product.
Product and model names stay as they are.
