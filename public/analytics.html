Agent usage

Planned runs
— runs whose compiled flow included the agent.
Executed runs
— runs whose execution report names the agent.
Invocations
— total times the agent ran, counting loops and retries.
Skipped
— runs where the taken path required the agent (per the flow's edges) and it never executed.
Off path
— runs where the flow took another branch, so the agent was correctly not executed. Does not count as Skipped.
Compliance
— Executed runs ÷ (Executed runs + Skipped). Off path runs are excluded.
